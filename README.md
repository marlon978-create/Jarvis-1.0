# Jarvis-1.0
Jarvis 1.0 is a local AI assistant inspired by Marvels Ironman. It was built using python and Ollama.
The goal for this project was to create a personal AI assistant that is better than Amazons Alexa, also that can run locally and respond to user input without relying on an openAI API.

#Demo
A demo video of Jarvis running is included in this repository and on my portfolio.

#Features
- Local AI responses using Ollama
- Python based backend
- case-insensitive user input
- Simple memory functionality

#Tech Stacks
-Python
-Ollama
-Local LLM

## What I learned
While building Jarvis I learned how to:

-Handling user input and responses
-building a simple memory system
-debugging and testing AI applications
